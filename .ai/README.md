# .ai 디렉토리

Claude Code 에이전트 시스템을 위한 참조 문서 모음입니다.

## 구조

```
.ai/
├── PROJECT_CONTEXT.md  # 프로젝트 전체 맥락
├── agents/             # 역할별 에이전트 지침서
├── skills/             # 공유 스킬 정의
└── workflows/          # 작업 워크플로우 문서
```

## 에이전트 목록
- `agents/` 디렉토리 참조

## 사용법
Claude Code 작업 시 이 디렉토리의 컨텍스트를 참조하여 일관된 코드 스타일과 아키텍처를 유지합니다.
